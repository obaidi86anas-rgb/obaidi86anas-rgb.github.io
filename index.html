Android App • com.opel.diagnostic.pro

Opel OBD

تطبيق تشخيص وفحص سيارات أوبل المباشر عبر فيشة ELM327 (بلوتوث، واي فاي، وكابل USB OTG) بدون الحاجة لتسجيل دخول.

تحميل تطبيق Opel OBD (APK)

قراءة ومسح الأعطال (DTC)

فحص أكواد أعطال المحرك النشطة والمعلقة (Mode 03 / Mode 07) ومسح لمبة الفحص (Mode 04) مع شرح كامل بالعربية.

دعم قير الإيزي ترونيك (Easytronic)

فحص وحدة التحكم بالقير (TCM 0x7E1) وبرمجة نقطة تعشيق الكلتش وأبعاد التروس وتنسيم الزيت.

عدادات وقراءات حية

مراقبة دورات المحرك RPM، حرارة سائل التبريد، فولتية البطارية، حساس الهواء، وضغط الوقود لحظياً.

دعم موديلات أوبل المتعددة

يدعم أوبل أسترا H و J و K، كورسا، فيكترا، وإنسينيا مع كود الأمان Car Pass PIN وموجه أوامر ELM327.
